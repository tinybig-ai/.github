# tinybig/.github

This repository holds the profile and the default files for the tinybig-ai
organization on GitHub.

- `profile/README.md` is the text on https://github.com/tinybig-ai.
- The other files in this repository are the defaults for all tinybig-ai
  repositories. If a repository has a file with the same name, the repository
  file wins.

Website: https://tinybig.ai
