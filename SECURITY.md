# Security

tinybig builds tools that run near your data and your machines. Send security
reports to us.

## How to report a vulnerability

Do not open a public issue. Use the private report form on the repository that
has the problem: go to the Security tab, then select Report a vulnerability. You
can also send email to cemre@tinybig.ai.

Include the project, the version, the effect, and the steps that cause the
problem. We will answer in a few days and tell you our progress.

## What to report

Send a report for a problem in a tinybig repository. This includes the daemon,
the clients, the cloud backend, and the use of secrets. A problem in your own
deployment, or in a dependency of tinybig, belongs to the owner of that
component.
